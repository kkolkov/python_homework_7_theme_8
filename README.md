## 🚀 Запуск программ

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Настройка API ключа
Перед запуском необходимо:
1. Получить API ключ на [OpenWeatherMap](https://openweathermap.org/api)
2. Создать файл `config.py` и добавить:
```python
OPENWEATHER_API_KEY = "your_api_key_here"
```

### Задание 3: Создание поста

## 🔧 Требования

- Python 3.6+
- Библиотеки: `requests`

## 📊 Описание задач

### Задание 1
- Отправляет GET-запрос к `/posts` JSONPlaceholder API
- Извлекает и выводит заголовки и тела первых 5 постов

### Задание 2
- Принимает название города от пользователя
- Отправляет GET-запрос к OpenWeather API
- Выводит текущую температуру и описание погоды

### Задание 3
- Отправляет POST-запрос для создания нового поста
- Выводит ID созданного поста и его содержимое

### Задание 4
- Обрабатывает различные коды состояния (200, 400, 404, 500)
- Выводит соответствующие сообщения об ошибках
